Socratic Multi-Agent Architecture & POC Blueprint

📊 Open Live Telemetry 🎙️ Launch Voice Session
AUDIO WEBSOCKET (16kHz PCM) → DYNOXIDE VECTOR DB → DYNAMIC GRAPH FSM → SHADOW EVALUATOR REST → BKT & MIRT BRAIN → POSTGRESQL ARCHIVE
1 Audio Pipeline & VAD

Browser captures 16kHz raw PCM audio. Streams bidirectionally to Gemini Live 3.1 preview model. Native speech-to-text (STT) and voice activity detection (VAD) allow natural conversational pacing with 0 candidate latency.

Web Audio API Gemini Live Audio
2 Dynoxide Vector DB

Candidate's introduction is converted to 768-D normalized embeddings. Dynoxide vector search matches the candidate's real projects to macro competency pillars without hardcoding candidate backgrounds.

Dynoxide / DynamoDB gemini-embedding-2
3 Dynamic Knowledge Graph

Dynamically spawns nodes from matched pillars. Injects topological prerequisite and co-requisite edges. Uses prerequisite gating (P(L) ≥ 0.50) and information-entropy distance to intelligently select Alex's next topic.

Dynamic Graph Entropy Routing
4 Polyglot Dialect Adaptation

Scans projects for programming ecosystems (Java JVM, Python asyncio/GIL, Go channels, Rust). Injects specific technical dialect directives into Alex's live prompt per project without locking the candidate into a single global language.

Ecosystem Service Prompt Injection
5 Quarantined Shadow Evaluator

Runs asynchronously via Gemini REST API in the background. Does not block voice dialogue. Generates structured JSON scoring concept depth, rubric items, and item difficulty (b ∈ [-1.5, +2.5]).

Gemini 2.5 Flash Dual-LLM Isolation
6 BKT Mathematical Engine

Executes deterministic Bayesian Knowledge Tracing. Calculates exact posterior mastery P(L_t) with slip, guess, and transit rates. Signals depth completion when mastery crosses 0.80 or 3 diagnostic turns are reached.

Exact Bayesian Math Deterministic FSM
7 Real 5D MIRT Ability Radar

Updates latent multidimensional ability vector (θ) across 5 canonical dimensions: algorithms, system design, concurrency, databases, and distributed systems. Computes standard errors and industry percentile rankings.

Multidimensional IRT Online Gradients
8 PostgreSQL Persistent Compaction

Epistemic compaction saves finalized topic cards and resets Gemini Live memory for the next topic. At interview conclusion, archives Student Career Compass and Evaluator Forensic Audit reports in PostgreSQL.

PostgreSQL 5432 Epistemic Compaction
