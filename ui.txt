Build a **React + Vite + Standard CSS** application called **Socratic Interview Engine Developer Console**, a desktop-first engineering dashboard for testing, debugging, and observing an AI-powered real-time voice interview platform.

This is **not a marketing website** and **not a generic analytics dashboard**.

The UI must resemble a realistic internal engineering tool built by a small team, similar to observability, AI tracing, and admin systems such as LangSmith, PostHog, Vercel Observability, or modern SaaS developer consoles.

---

# Technical Stack

Use:

- React + Vite
- Standard CSS only
- React Router
- Context API or Zustand
- Recharts for mini charts
- Lucide React icons
- Framer Motion (small animations only)

Avoid:

- Tailwind
- Material UI
- Heavy animations
- Glassmorphism
- Excessive gradients

# Important UI Rules

The user must immediately understand:

1. What is happening in the interview right now.
2. Which engines are active.
3. What changed after a candidate answer.
4. Which backend systems executed.
5. What failed.
6. Which scores are intermediate vs final.

Do not create:

- marketing pages
- huge charts
- empty cards
- fake AI art
- dark theme
- oversized components

Build this as a realistic, information-dense engineering dashboard suitable for a proof-of-concept AI interview platform with FastAPI backend integration.
